    METHOD & GOVERNANCE

    完整功能的关键，是同源、可追溯、可验证。

    远端只替换交互层，不复制算法。所有科学计算仍由项目中的 CNTAnalyzer 执行。

    01WEB WORKSPACE

    浏览器工作台

    负责上传、画布比例尺与 ROI、参数控制、结果图表和文件下载。

    02SESSION API

    会话与任务层

    限制上传大小和并发，会话过期清理；组图分析在后台执行并报告进度。

    03SHARED CORE

    CNTAnalyzer

    与桌面端共用 Python/OpenCV 核心，执行预处理、骨架、轮廓和逐根测量。

    04VERIFICATION

    一致性闭环

    固定样图同时走核心与 HTTP 路径，逐项比较数量、长度、宽度与统计指标。

    CALIBRATION

    完整校准与 ROI

    • 自动比例尺条与文字识别
    • 画布手动标尺校准
    • 比例尺区域自动排除
    • 多个自定义 ROI 独立分析
    MEASUREMENT

    逐根骨架测量

    • 自适应阈值与形态处理
    • 骨架图直径路径测量
    • 粘连拆分与近邻合并
    • 长度、宽度与长宽比输出
    SPATIAL

    空间与团聚统计

    • 最近邻 CV 与 NNI
    • 点密度、覆盖率与阴影网格
    • Moran's I、熵与占用率
    • 热点团聚和分散比例
    DELIVERY

    对比与完整交付

    • 双图及 base/实验组对比
    • Welch t 与 Mann-Whitney 检验
    • JSON、CSV、TXT 报告
    • 轮廓与骨架 PNG 结果
    DATA LIFECYCLE

    原图如何处理

    1. 上传通过 HTTPS 发送到 Ali 服务器，仅用于本次分析。
    2. 处理单图保存在内存会话；批量图暂存于受限任务目录。
    3. 释放单图会话无操作后过期；批量任务生成结果后立即删除原始上传。
    4. 交付结果由用户主动下载，服务端不将原图写入项目数据集。
